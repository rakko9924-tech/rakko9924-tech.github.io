花札こいこい

和紙と墨の花札。CPU・オンライン・ランク戦・今日の一局

アプリについて

花札の「こいこい」を、ひとりでも、だれかとでも遊べるアプリです。同じ花の札を取り合って役を作り、「勝負」で点をもらうか、「こいこい」でもっと大きな役を狙うかを決めます。

  • CPU は3段階。「つよい」は見えていない札を何通りも先読みして打ちます（相手の手札や山札は覗きません）
  • オンライン対戦（だれかと・合言葉で友だちと）
  • ランク戦：全員が同じ配り・同じ CPU と打って点差を比べるので、待たずに遊べて運の差がつきません
  • 今日の一局：毎日ひとつの配りを全員で。その日の順位表つき
  • 1回ごとの振り返り：自分の手と、つよい CPU ならどう打ったかを見比べられます
  • 役の図鑑と記録、初めての方向けのチュートリアル（札の見方から、実際に打ちながら覚えられます）とヒント
  • 札に花の名前の名札を出せます（どの札でどの札が取れるかが分かります。設定で切り替え）
